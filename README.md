# Ninad & Neha Wedding Invitation

A responsive, single-page wedding invitation with a generated Indian wedding-inspired background, animated petals and sparkles, an opening interaction, and a live countdown.

## Preview locally
Open `index.html` in a modern browser. Internet access is used only for the Google Fonts; the decorative background is included in `assets/wedding-arch.png`.

## Publish free with GitHub Pages
1. Create a new public repository on GitHub.
2. Upload the contents of this folder (make sure `index.html` is at the repository root).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. GitHub will provide the public website URL after deployment.

## Personalise before publishing
The source link exposed the names and date, but not the full ceremony details. Add the venue, ceremony timings, family names, RSVP contact, and any additional events in `index.html` once confirmed. The current date shown is 24 November 2026.
